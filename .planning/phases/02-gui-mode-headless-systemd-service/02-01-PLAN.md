  <action>
Create the IPresenter pure virtual interface at src/presenter/ipresenter.h with these methods:
- `virtual bool start() = 0` -- called once after camera and writer are initialized. Returns false if presenter cannot start.
- `virtual bool tick() = 0` -- called in main loop. Returns false when presenter wants to quit. GUI: renders one frame. Headless: watchdog ping, disk check.
- `virtual void shutdown() = 0` -- called on shutdown. Flush final status, destroy resources.
- `virtual void on_camera_disconnect() = 0` -- notifies presenter that camera disconnected.
- `virtual void on_camera_reconnect() = 0` -- notifies presenter that camera reconnected.
- `virtual void update_stats(const Stats& stats) = 0` -- passes latest stats for display/reporting.
- Virtual destructor `virtual ~IPresenter() = default`.
Include forward declarations for Stats. Include a `#pragma once` guard.

Create the Config system at src/config/config.h and src/config/config.cpp:
- Config struct with fields: `output_dir` (string, default "."), `session_name` (string, default "capture"), `jpeg_quality` (int, default 90), `zstd_level` (int, default 1), `queue_size` (int, default 4), `warmup_frames` (int, default 30), `disk_min_mb` (uint64_t, default 500), `headless` (bool, default false), `config_path` (string, default "").
- `Config load_config(const std::string& path)` function: uses toml++ v3.4.0 to parse the file. Uses `value_or()` for all reads so missing keys use defaults. Catches `toml::parse_error` and returns defaults if file is missing or malformed. Logs a warning to stderr on parse error.
- TOML structure: `[output]` section with `dir`, `[compression]` section with `jpeg_quality` and `zstd_level`, `[recording]` section with `disk_min_mb`, `queue_size`, `warmup_frames`.
- Use `#include <toml++/toml.hpp>` (toml++ is header-only via FetchContent).

Create config.toml.example at project root with all settings documented with comments explaining each value, its default, and valid range.
  </action>
