**src/threading/bounded_queue.h:**
- Header-only template class `BoundedQueue<T>`
- Uses `std::queue<T>`, `std::mutex`, `std::condition_variable`
- Constructor takes `size_t max_size`
- `push(T item)`: lock guard, if queue full pop oldest and increment `dropped_` counter, push new item, notify one on `not_empty_`
- `pop() -> std::optional<T>`: unique lock, wait on `not_empty_` until `!queue_.empty() || closed_`, if empty return nullopt (closed), else move front and return
- `close()`: set `closed_ = true`, notify all on `not_empty_`
- `dropped() const -> size_t`: return dropped count (lock guard)
- `size() const -> size_t`: return queue size (lock guard)
- Private members: `queue_`, `mutex_` (mutable), `not_empty_`, `max_size_`, `closed_` (bool, init false), `dropped_` (size_t, init 0)

**src/compression/jpeg_compressor.h/.cpp:**
- `#include <turbojpeg.h>`
- Class `JpegCompressor` (non-copyable, non-movable -- owns C handle)
- Constructor: `JpegCompressor(int width, int height, int quality = 90)`
  - `tjInitCompress()` into `handle_`, throw `std::runtime_error` on failure
  - Pre-allocate buffer: `buf_size_ = tjBufSize(width, height, TJSAMP_420)`, allocate with `tjAlloc(buf_size_)` into `buf_`
  - Store `quality_`, `width_`, `height_`
- Destructor: `tjFree(buf_)`, `tjDestroy(handle_)`
- `compress(const uint8_t* rgb, int width, int height) -> std::pair<const uint8_t*, size_t>`
  - `unsigned long compressed_size = buf_size_;`
  - `unsigned char* out_buf = buf_;`
  - Call `tjCompress2(handle_, rgb, width, 0, height, TJPF_RGB, &out_buf, &compressed_size, TJSAMP_420, quality_, TJFLAG_FASTDCT | TJFLAG_NOREALLOC)`
  - Check return != 0, throw with `tjGetErrorStr2(handle_)` on error
  - Return `{buf_, compressed_size}`
- IMPORTANT: Use `TJFLAG_NOREALLOC` to prevent per-frame allocation. Use `TJSAMP_420` for 4:2:0 chroma subsampling (per research -- 30% smaller, sufficient for ML training).

**src/compression/zstd_compressor.h/.cpp:**
- `#include <zstd.h>`
- Class `ZstdCompressor` (non-copyable, non-movable -- owns C context)
- Constructor: `ZstdCompressor(size_t max_input_size, int level = 1)`
  - `ZSTD_createCCtx()` into `ctx_`, throw on null
  - `buf_.resize(ZSTD_compressBound(max_input_size))`
  - Store `level_`
- Destructor: `ZSTD_freeCCtx(ctx_)`
- `compress(const void* src, size_t src_size) -> std::pair<const uint8_t*, size_t>`
  - `ZSTD_compressCCtx(ctx_, buf_.data(), buf_.size(), src, src_size, level_)`
  - Check `ZSTD_isError(result)`, throw with `ZSTD_getErrorName(result)` on error
  - Return `{buf_.data(), result}`
- Use level 1 as default (fastest, per research -- <0.5ms for 614KB depth frame, 3.0-3.5:1 ratio)
