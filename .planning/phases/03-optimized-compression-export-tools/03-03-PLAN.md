**EgorecFile class design:**

The class opens a .egorec file, reads the header and footer (for frame count), and provides:
- `header()` - returns a Python dict with all file metadata
- `frame_count()` - returns total frame count
- `frames()` - returns a Python iterator that yields decoded frame dicts

**Internal state:**
- `std::ifstream file_` - opened in binary mode
- `FileHeader header_` - read at construction
- `FileFooter footer_` - read at construction (seek to end - sizeof(FileFooter))
- `bool has_footer_` - whether footer was valid
- `std::vector<IndexEntry> index_` - read from footer's index_offset if has_footer_
- `ZdepthCompressor zdepth_decomp_` - for depth decompression (width, height from header)
- H.264 decoder state (AVCodecContext, SwsContext for YUV420P->RGB24 conversion)

**Construction (`EgorecFile(const std::string& path)`):**
1. Open file in binary read mode. Throw if failed.
2. Read FileHeader. Validate magic starts with "EGOREC". Check magic[6] == 0x02 (v2 only, per locked decision: "V1 .egorec files NOT supported by export tools -- v2 only"). Throw descriptive error if v1.
3. Read footer: seek to end - sizeof(FileFooter), read FileFooter, validate footer_magic.
4. If footer valid, read index table: seek to footer.index_offset, read footer.index_entry_count IndexEntry items.
5. Initialize ZdepthCompressor with header's depth dimensions.
6. Initialize H.264 decoder:
   - `avcodec_find_decoder(AV_CODEC_ID_H264)` - find the decoder (NOT encoder)
   - Allocate AVCodecContext, open codec
   - Allocate AVFrame for YUV output
   - Allocate AVPacket for input
   - Create SwsContext for YUV420P -> RGB24 conversion (output dimensions from header)
   - Allocate an RGB24 output buffer (width * height * 3)
7. Seek file position back to `sizeof(FileHeader)` (start of frame data).

**`header()` method:**
Return a `py::dict` with all fields from FileHeader:
```python
{
    "session_name": str,
    "format_version": int (header_.magic[6]),
    "frame_count": int (from footer if valid, else -1),
    "duration_s": float (from footer if valid),
    "start_ts_us": int,
    "depth_width": int, "depth_height": int,
    "color_width": int, "color_height": int,
    "depth_scale": float,
    "depth_fx": float, "depth_fy": float,
    "depth_ppx": float, "depth_ppy": float,
    "depth_distortion_model": int,
    "depth_distortion": list[float] (5 coefficients),
    "color_fx": float, "color_fy": float,
    "color_ppx": float, "color_ppy": float,
    "color_distortion_model": int,
    "color_distortion": list[float] (5 coefficients),
    "extrinsic_R": list[float] (9 values, row-major 3x3),
    "extrinsic_t": list[float] (3 values),
    "rgb_codec": int,
    "depth_codec": int,
    "has_imu": bool (flags & 0x01),
    "serial_number": str,
    "usb_type": str,
}
```

**`frame_count()` method:**
Return `footer_.total_frames` if has_footer_, else iterate and count (expensive fallback).

**`frames()` method -- frame iterator:**
Return a Python generator-like object. Use `py::iterator` or implement `__iter__` and `__next__`.

The simplest approach: return a `py::list` of dicts (materialized). But for large files this uses too much memory. Instead, implement an iterator class `FrameIterator`:

```cpp
struct FrameIterator {
    EgorecFile* file;
    uint64_t current_frame;
    uint64_t total_frames;

    py::dict next() {
        if (current_frame >= total_frames) {
            throw py::stop_iteration();
        }
        return file->read_frame(current_frame++);
    }
};
```

Register FrameIterator with `__iter__` (returns self) and `__next__` (calls next()).

**`read_frame(uint64_t index)` internal method:**
1. If we have the index table, seek to index_[index].file_offset. Otherwise, read sequentially (file position already at next frame from previous read).
2. Read FrameBlockHeader. Validate magic == FRAME_MAGIC.
3. Read rgb_compressed_size bytes of H.264 data.
4. Read depth_compressed_size bytes of Zdepth data.
5. Skip imu_sample_count * sizeof(IMUSampleWire) bytes (IMU data not exported to Python in this version).

**H.264 decode:**
- If rgb_compressed_size > 0:
  - Create an AVPacket from the raw H.264 bytes, set pkt->data and pkt->size.
  - Call `avcodec_send_packet(ctx_, pkt_)`.
  - Call `avcodec_receive_frame(ctx_, yuv_frame_)`. If EAGAIN, the decoder needs more data -- store a flag and return None for RGB this frame (or handle differently).
  - If frame received: convert YUV420P -> RGB24 via `sws_scale`.
  - Create numpy array: `py::array_t<uint8_t>({height, width, 3})`, memcpy the RGB24 data into the array's mutable buffer.
- If rgb_compressed_size == 0:
  - This is a frame where the H.264 encoder returned empty data (buffering). Set RGB to None or a zero-filled array. Actually, check if the decoder has any buffered output from previous sends.

**IMPORTANT decoder subtlety:** The encoder might have returned empty data for frame N, then returned frame N's encoded data along with frame N+1's data. The decoder sees both packets when processing frame N+1. So `avcodec_receive_frame` might produce TWO frames when processing a single packet. Handle this by calling receive_frame in a loop until EAGAIN, queueing decoded frames internally, and returning them one-by-one to Python.

Use an internal `std::deque<std::vector<uint8_t>>` to buffer decoded RGB frames. When the decoder produces multiple frames from one packet, push them all to the deque. The next call to read_frame pops from the deque first before reading more packets.

**Zdepth decompress:**
- If depth_compressed_size > 0:
  - Call `zdepth_decomp_.decompress(depth_data, depth_size)` to get `std::vector<uint16_t>`.
  - Create numpy array: `py::array_t<uint16_t>({height, width})`, copy the decompressed data.
- If depth_compressed_size == 0: return zero-filled depth array.

**Frame dict returned to Python:**
```python
{
    "timestamp_us": int,
    "timestamp_relative_s": float,  # (timestamp_us - start_ts_us) / 1e6
    "frame_number": int,
    "rgb": np.ndarray(dtype=uint8, shape=(H, W, 3)),
    "depth": np.ndarray(dtype=uint16, shape=(H, W)),
}
```

**Destruction:**
- Free AVCodecContext, AVFrame, AVPacket, SwsContext
- Close file
- ZdepthCompressor destructs automatically via RAII

**H.264 decoder flush at end of file:**
When frame_count is reached, call `avcodec_send_packet(ctx_, nullptr)` to flush the decoder. Then drain any remaining frames with `avcodec_receive_frame` loop. Push these to the decoded frame deque so the iterator can return them.

**PYBIND11_MODULE definition:**
```cpp
namespace py = pybind11;

PYBIND11_MODULE(egorec_reader, m) {
    m.doc() = "C++ reader for .egorec v2 files";

    py::class_<FrameIterator>(m, "FrameIterator")
        .def("__iter__", [](FrameIterator& self) -> FrameIterator& { return self; })
        .def("__next__", &FrameIterator::next);

    py::class_<EgorecFile>(m, "EgorecFile")
        .def(py::init<const std::string&>())
        .def("header", &EgorecFile::header)
        .def("frame_count", &EgorecFile::frame_count)
        .def("frames", &EgorecFile::frames_iterator,
             py::keep_alive<0, 1>());  // iterator refs file
}
```

Use `py::keep_alive<0, 1>()` on frames() to ensure the EgorecFile stays alive while the iterator exists.
