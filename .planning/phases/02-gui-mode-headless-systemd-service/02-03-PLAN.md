Create HeadlessPresenter implementing IPresenter at src/presenter/headless_presenter.h and headless_presenter.cpp.

**Header (headless_presenter.h):**
- `#pragma once`, include ipresenter.h, config.h, stats.h
- Wrap sd_notify and sd_bus related code in `#ifdef HAVE_SYSTEMD` guards (graceful degradation without libsystemd)
- Class HeadlessPresenter : public IPresenter
- Constructor takes `const Config& config` and a callback `std::function<void()> on_request_shutdown` for signaling main to stop (used when disk is full)
- Private members: config ref, watchdog thread, shutdown atomic bool, inhibitor_fd_ (int, -1), sd_bus* bus_ (nullptr), status_file_path_ (string), latest stats cache, tick_counter_ for periodic checks

**Implementation (headless_presenter.cpp):**

**start():**
1. Take D-Bus inhibitor lock (block "handle-lid-switch:sleep"):
   - sd_bus_open_system(&bus_)
   - sd_bus_call_method on "org.freedesktop.login1" / "/org/freedesktop/login1" / "org.freedesktop.login1.Manager" / "Inhibit" with signature "ssss": "handle-lid-switch:sleep", "ego-recorder", "Recording in progress", "block"
   - Read reply with "h" to get fd, then `inhibitor_fd_ = dup(inhibitor_fd_)` BEFORE sd_bus_message_unref (critical -- see research pitfall 5)
   - Log success/failure to stderr. Non-fatal if lock fails (logind.conf fallback exists)
2. Start watchdog thread:
   - Call sd_watchdog_enabled(0, &interval_us). If enabled <= 0, skip watchdog thread.
   - Compute ping_interval = interval_us / 2 (per systemd spec)
   - Spawn thread that loops: sd_notify(0, "WATCHDOG=1"), sd_notifyf STATUS with frame count + FPS + disk free, sleep for ping_interval, until shutdown_ is true
3. Send sd_notify(0, "READY=1") -- ONLY after camera is confirmed open and recording started (this method is called after camera init in main.cpp)
4. Write initial status file at /run/ego-recorder/status (or config-derived path): JSON format with pid, state, timestamp
5. Log "Headless mode started" to stderr
6. Return true

**tick():**
1. Increment tick_counter_
2. Every 30 ticks (~1 second at 30fps loop or use time-based check):
   - Check disk space via std::filesystem::space(config_.output_dir)
   - If free MB < config_.disk_min_mb: log "Disk space below threshold", call on_request_shutdown_(), return false
   - Update status file with latest stats (frames, fps, disk free, recording state)
3. Sleep briefly (100ms) to avoid busy-wait in headless mode (unlike GUI which is vsync-limited)
4. Return !shutdown_.load()

**shutdown():**
1. shutdown_.store(true)
2. If watchdog thread is joinable, join it
3. Send sd_notify(0, "STOPPING=1")
4. Release inhibitor lock: close(inhibitor_fd_), sd_bus_unref(bus_)
5. Update status file one final time with state="stopped"
6. Log "Headless mode stopped" to stderr

**on_camera_disconnect():**
- Log "Camera disconnected, waiting for reconnect..." to stderr
- Update status file with state="disconnected"
- sd_notifyf STATUS "Camera disconnected - waiting for reconnect"

**on_camera_reconnect():**
- Log "Camera reconnected" to stderr
- Update status file with state="recording"
- sd_notifyf STATUS "Camera reconnected - recording resumed"

**update_stats():** Cache stats values for status file and sd_notify STATUS updates

**Private helpers:**
- `bool take_inhibitor_lock()` -- D-Bus inhibitor logic (separated for clarity)
- `void release_inhibitor_lock()` -- close fd, unref bus
- `void write_status_file(const std::string& state)` -- write JSON to /run/ego-recorder/status: `{"pid": N, "state": "recording|stopped|disconnected", "frames": N, "fps": N.N, "disk_free_mb": N, "timestamp": "ISO8601"}`
- `uint64_t disk_free_mb()` -- std::filesystem::space with error_code, returns UINT64_MAX on error

Gate all sd_notify/sd_bus calls behind `#ifdef HAVE_SYSTEMD` so the headless presenter still works (without watchdog/inhibitor) on non-systemd systems.

**deploy/ego-recorder.service** (systemd unit):
```ini
[Unit]
Description=ego-recorder headless RGBD capture
After=local-fs.target

[Service]
Type=notify
User=ego-recorder
Group=ego-recorder
ExecStart=/usr/local/bin/ego-recorder --headless --config /etc/ego-recorder/config.toml
Restart=on-failure
RestartSec=5s
WatchdogSec=30s
NotifyAccess=main
RuntimeDirectory=ego-recorder
RuntimeDirectoryMode=0750
OOMScoreAdjust=-100

[Install]
WantedBy=multi-user.target
```
Note: RuntimeDirectory=ego-recorder auto-creates /run/ego-recorder with correct ownership.

**deploy/99-ego-recorder.rules** (udev):
- RealSense D435 (8086:0b07) and D435i (8086:0b3a) rules
- MODE:="0660", GROUP:="plugdev"
- ATTR{power/control}="on" to disable USB autosuspend (NFR-4.4)
- Comment noting that the full upstream list is in librealsense/config/99-realsense-libusb.rules

**deploy/50-ego-recorder-lid.conf** (logind.conf drop-in):
- [Login] section with HandleLidSwitch=ignore, HandleLidSwitchExternalPower=ignore
- Comment: "Fallback for lid-close prevention. The D-Bus inhibitor lock in headless_presenter.cpp is the preferred approach (process-scoped). This file is machine-wide and should only be used if the inhibitor lock fails."

**deploy/install.sh:**
- `#!/usr/bin/env bash` with `set -euo pipefail`
- Check root (if not root, echo error and exit)
- Create system user `ego-recorder` (useradd --system --no-create-home --shell /usr/sbin/nologin) with idempotent check
- Add to groups: plugdev, video
- Install binary to /usr/local/bin/ego-recorder (install -m 755)
- Create /etc/ego-recorder/, install config.toml.example as config.toml (install -m 644), only if config.toml doesn't already exist (don't overwrite user edits)
- Install systemd unit to /etc/systemd/system/, daemon-reload
- Install udev rules to /etc/udev/rules.d/, reload rules + trigger
- Install logind drop-in to /etc/systemd/logind.conf.d/, restart systemd-logind
- Enable service (don't start -- let user start manually or reboot)
- Print summary of what was installed

**deploy/config.toml.example:**
- Copy of config.toml.example from project root but with headless-appropriate defaults:
  - output.dir = "/var/lib/ego-recorder/recordings"
  - recording.disk_min_mb = 1000 (more conservative for production)
  - Comments explaining each setting

Per user locked decision: install.sh is a single `sudo ./install.sh` command. Auto-generated session names in headless mode (handled by main.cpp in plan 04).
