**Header (gui_presenter.h):**
- `#pragma once`, include ipresenter.h, config.h, stats.h, frame_types.h
- Wrap entire file in `#ifdef HAVE_GUI` / `#endif` preprocessor guard
- Class GuiPresenter : public IPresenter
- Constructor takes `const Config& config` and a callback interface or function pointers for:
  - `std::function<void()> on_start_recording` -- called when user clicks Start
  - `std::function<void()> on_stop_recording` -- called when user clicks Stop
  - `std::function<void(const std::string&)> on_session_name_changed` -- passes session name
- Public method `void update_frame(const uint8_t* rgb_data, const uint16_t* depth_data, int width, int height, float depth_scale)` -- called by capture thread to provide latest frame for display. Uses `std::mutex` to protect a shared frame buffer (or double-buffer approach). The GUI reads the latest buffer in tick(). This is the simplest correct approach -- lock contention is minimal since the GUI only reads once per render frame (~60fps) and capture writes once per camera frame (~30fps).
- Public bool `is_recording() const` and `std::string session_name() const` getters
- Enum ViewMode { RGB_ONLY, DEPTH_ONLY, SIDE_BY_SIDE } private member, default SIDE_BY_SIDE
- Private members: GLFWwindow*, GLuint rgb_tex_, depth_tex_, ImGui context state, session_name_ string, recording_ bool, view_mode_, stats cache, disconnect state bool, config reference

**Implementation (gui_presenter.cpp):**

**start():**
1. glfwSetErrorCallback with stderr logging
2. glfwInit() -- return false on failure
3. glfwWindowHint: CONTEXT_VERSION_MAJOR=3, MINOR=0
4. glfwCreateWindow(1280, 720, "ego-recorder", nullptr, nullptr) -- return false on failure
5. glfwMakeContextCurrent(window_)
6. glfwSwapInterval(1) -- vsync ON
7. IMGUI_CHECKVERSION(), ImGui::CreateContext(), ImGui::StyleColorsDark()
8. ImGui_ImplGlfw_InitForOpenGL(window_, true)
9. ImGui_ImplOpenGL3_Init("#version 130")
10. Create OpenGL textures for RGB and depth: glGenTextures, glBindTexture, glTexParameteri(MIN/MAG_FILTER, GL_LINEAR), glPixelStorei(GL_UNPACK_ROW_LENGTH, 0), glTexImage2D(GL_TEXTURE_2D, 0, GL_RGB, 640, 480, 0, GL_RGB, GL_UNSIGNED_BYTE, nullptr)
11. Allocate colorized depth buffer (640*480*3 bytes)
12. Return true

**tick():**
1. if (glfwWindowShouldClose(window_)) return false
2. glfwPollEvents()
3. ImGui_ImplOpenGL3_NewFrame(), ImGui_ImplGlfw_NewFrame(), ImGui::NewFrame()
4. Lock mutex, copy latest frame data to local buffers, unlock
5. Upload RGB texture: glBindTexture + glTexSubImage2D with local RGB buffer
6. Apply jet colormap to depth data -> colorized buffer, then upload depth texture similarly
7. Render preview window(s) based on view_mode_:
   - RGB_ONLY: single ImGui::Image with rgb_tex_ scaled to window size
   - DEPTH_ONLY: single ImGui::Image with depth_tex_ scaled to window size
   - SIDE_BY_SIDE: two ImGui::Image side by side, each taking half the available width
   - Use glfwGetFramebufferSize for available space, scale maintaining 4:3 aspect ratio
8. Render controls panel (can be overlaid or docked at bottom):
   - ImGui::InputText("Session Name", &session_name_) using imgui_stdlib.h
   - Start/Stop button: disabled (ImGui::BeginDisabled/EndDisabled) when session_name_ is empty
   - Button text: "Stop Recording (Space)" when recording_, "Start Recording (Space)" when not
   - Show disconnect banner with "Reconnect" button when disconnected_ is true
9. Render stats overlay (semi-transparent):
   - Use ImGui::SetNextWindowBgAlpha(0.5f) for semi-transparency
   - Position in top-right corner using ImGui::SetNextWindowPos with ImGuiCond_Always
   - Display: FPS (capture + write), frame count (captured/written), dropped frames, bytes written (formatted as MB/GB), elapsed time, disk free space
   - Use ImGui::Begin with ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_AlwaysAutoResize | ImGuiWindowFlags_NoFocusOnAppearing | ImGuiWindowFlags_NoNav
10. Handle keyboard shortcuts (guarded by !ImGui::GetIO().WantCaptureKeyboard):
    - ImGuiKey_Space: toggle recording (call on_start_recording or on_stop_recording callback)
    - ImGuiKey_Tab: cycle view_mode_ (RGB_ONLY -> DEPTH_ONLY -> SIDE_BY_SIDE -> RGB_ONLY)
    - ImGuiKey_Escape: return false (quit)
11. ImGui::Render(), get framebuffer size, glViewport, glClear(GL_COLOR_BUFFER_BIT), ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData()), glfwSwapBuffers(window_)
12. Return true

**Jet colormap function** (private helper or free function in cpp):
- `void z16_to_jet_rgb(const uint16_t* depth, uint8_t* out_rgb, int width, int height, float depth_scale, float near_m = 0.1f, float far_m = 10.0f)`
- For each pixel: if depth[i] == 0, output black (0,0,0). Otherwise normalize to [0,1] range between near_m and far_m. Apply jet colormap math:
  - r = clamp(1.5 - abs(4*t - 3), 0, 1)
  - g = clamp(1.5 - abs(4*t - 2), 0, 1)
  - b = clamp(1.5 - abs(4*t - 1), 0, 1)
- Per user decision: blue=near, red=far (jet colormap standard)

**shutdown():**
- ImGui_ImplOpenGL3_Shutdown(), ImGui_ImplGlfw_Shutdown(), ImGui::DestroyContext()
- glDeleteTextures for both textures
- glfwDestroyWindow(window_), glfwTerminate()

**on_camera_disconnect():** Set disconnected_ = true (GUI will show reconnect banner)
**on_camera_reconnect():** Set disconnected_ = false
**update_stats():** Cache stats values for overlay rendering
**update_frame():** Lock mutex, copy rgb_data and depth_data into internal buffers, unlock

IMPORTANT anti-patterns to avoid (from research):
- Do NOT use glTexImage2D every frame -- use glTexSubImage2D (already specified above)
- Do NOT check keyboard shortcuts without !io.WantCaptureKeyboard guard -- Space would fire inside InputText
- Do NOT create textures before glfwMakeContextCurrent -- texture handle 0 is ImGui font atlas
- Cast texture IDs as `(ImTextureID)(intptr_t)rgb_tex_` for strict aliasing safety
