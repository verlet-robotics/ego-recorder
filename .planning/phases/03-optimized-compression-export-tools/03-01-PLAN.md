```
class ZdepthCompressor {
public:
    ZdepthCompressor(int width, int height);
    ~ZdepthCompressor();
    // Non-copyable, non-movable

    // Compress a Z16 depth frame. Returns {pointer, size}.
    // Pointer valid until next compress() call.
    // keyframe=true forces an I-frame (must be true for first frame and every ~30 frames).
    std::pair<const uint8_t*, size_t> compress(const uint16_t* depth, int width, int height, bool keyframe);

    // Decompress a Zdepth-compressed buffer back to Z16.
    // Returns a vector of uint16_t (width * height elements).
    // Used for round-trip verification and by the Python reader.
    std::vector<uint16_t> decompress(const uint8_t* data, size_t size);
};
```

**zdepth_compressor.cpp:**
- Include `zdepth.hpp` from the catid/Zdepth library
- Constructor: create a `zdepth::DepthCompressor` instance. Store width/height.
- compress(): Call `compressor_.Compress(width, height, depth, compressed_buf_, keyframe)`. Use the keyframe parameter to control whether this is an I-frame. Return pointer to internal `compressed_buf_` (a `std::vector<uint8_t>` member).
- decompress(): Create a separate `zdepth::DepthCompressor` decompressor instance (or reuse one stored as member). Call `decompressor_.Decompress(data_vec, out_width, out_height, out_depth)`. Return the decompressed uint16_t vector.
- Use encode mode appropriate for D435: inspect Zdepth's API for set_encode_mode or similar. If the Zdepth API doesn't expose mode selection, use defaults (the library auto-detects based on data range).
- Destructor: default (Zdepth manages its own resources).

**Important:** The Zdepth compress API signature may differ slightly from the research notes. Read the actual `zdepth.hpp` header after FetchContent downloads it (it will be in `build_v2/_deps/zdepth-src/include/`). Adapt the wrapper to match the actual API. The key contract is: takes uint16_t* depth, returns compressed bytes, and round-trip is lossless.

Create an H264Encoder class wrapping FFmpeg's libavcodec for real-time H.264 encoding.

**h264_encoder.h:**
```
class H264Encoder {
public:
    H264Encoder(int width, int height, int fps = 30, int crf = 23);
    ~H264Encoder();
    // Non-copyable, non-movable

    // Encode one RGB24 frame. Returns compressed H.264 NAL units.
    // May return empty vector for buffered frames.
    // Internally converts RGB24 -> YUV420P via libswscale.
    std::vector<uint8_t> encode(const uint8_t* rgb24, int width, int height);

    // Flush remaining buffered frames at end of recording.
    // Returns concatenated NAL units for all remaining frames.
    std::vector<uint8_t> flush();

    // Reset encoder state for a new recording session.
    // Must be called when starting a new file (after reconnect etc).
    void reset();
};
```

**h264_encoder.cpp:**
- Include FFmpeg headers inside `extern "C" { }` block:
  - `<libavcodec/avcodec.h>`
  - `<libavutil/opt.h>`
  - `<libavutil/imgutils.h>`
  - `<libswscale/swscale.h>`

**Constructor:**
- Find encoder: `avcodec_find_encoder_by_name("libx264")` -- assert non-null
- Allocate context: `avcodec_alloc_context3(codec)`
- Configure: width, height, time_base={1, fps}, framerate={fps, 1}, pix_fmt=AV_PIX_FMT_YUV420P, gop_size=fps (one keyframe per second), max_b_frames=0 (no B-frames for real-time)
- Set CRF: `av_opt_set(ctx->priv_data, "preset", "fast", 0)` and `av_opt_set(ctx->priv_data, "crf", std::to_string(crf).c_str(), 0)`
- Open codec: `avcodec_open2(ctx, codec, nullptr)` -- check return
- Allocate AVFrame for YUV420P: `av_frame_alloc()`, set width/height/format, `av_frame_get_buffer(frame, 0)`
- Allocate AVPacket: `av_packet_alloc()`
- Create SwsContext: `sws_getContext(width, height, AV_PIX_FMT_RGB24, width, height, AV_PIX_FMT_YUV420P, SWS_FAST_BILINEAR, ...)`
- Initialize frame_counter_ = 0

**encode():**
- Assert width/height match constructor values (assert even dimensions)
- Convert RGB24 -> YUV420P: `sws_scale(sws_, src_data, src_linesize, 0, height, yuv_frame_->data, yuv_frame_->linesize)`
- Set PTS: `yuv_frame_->pts = frame_counter_++` (monotonically increasing)
- Send frame: `avcodec_send_frame(ctx_, yuv_frame_)`
- Receive packets in loop: `avcodec_receive_packet(ctx_, pkt_)` until EAGAIN/EOF
- Concatenate all pkt->data into output vector, `av_packet_unref` after each
- Return the vector (may be empty if encoder is buffering)

**flush():**
- Send null frame: `avcodec_send_frame(ctx_, nullptr)`
- Receive remaining packets same as encode()
- Return concatenated data

**reset():**
- Close and reopen the codec context with same parameters
- Reset frame_counter_ = 0
- This is needed when starting a new .egorec file after camera reconnect

**Destructor:**
- `sws_freeContext(sws_)`
- `av_frame_free(&yuv_frame_)`
- `av_packet_free(&pkt_)`
- `avcodec_free_context(&ctx_)`

**Width/height guard:** Assert `width % 2 == 0 && height % 2 == 0` in constructor (YUV420P requires even dimensions). D435 640x480 is fine but guard anyway.
