**1. CLI Parsing (cxxopts):**
```cpp
#include <cxxopts.hpp>
```
Options:
- `-o, --output` (string, default "."): Output directory
- `-s, --session-name` (string, default "capture"): Session name (used in filename)
- `-d, --duration` (int, default 0): Max recording duration in seconds (0 = unlimited)
- `-q, --quality` (int, default 90): JPEG quality (1-100)
- `-z, --zstd-level` (int, default 1): ZSTD compression level (1-22)
- `--queue-size` (int, default 4): Bounded queue size (2-16)
- `--warmup` (int, default 30): Camera warmup frames to skip
- `-h, --help`: Print usage

Validate: quality in [1,100], zstd-level in [1,22], queue-size in [2,16]. Print error and exit on invalid.

Generate output filename: `{output_dir}/{session_name}_{timestamp}.egorec` where timestamp is `YYYYMMDD_HHMMSS` format from system clock.

**2. Initialization Sequence (in main, before threads):**

a. Call `setup_signal_handling(shutdown_flag)` FIRST -- before any thread creation. This blocks SIGTERM/SIGINT in the main thread, and all subsequently spawned threads inherit the blocked mask.

b. Create `RealSensePipeline camera`
c. Call `camera.configure_and_start(warmup_frames)`
d. Print camera info to stderr:
   ```
   Camera: {serial_number} (USB {usb_type})
   IMU: {detected/not detected}
   Recording to: {output_filepath}
   Press Ctrl+C to stop recording.
   ```

e. Create `FileWriter writer(output_filepath)`
f. Create `FileHeader header`; call `camera.populate_header(header)`
g. Set `header.session_name` from CLI arg, `header.start_timestamp_us` from system clock (microseconds since epoch), `header.rgb_quality` from CLI, `header.zstd_level` from CLI
h. Call `writer.write_header(header)`

i. Create `BoundedQueue<CapturedFrame> queue(queue_size)`
j. Create `Stats stats`
k. Create `JpegCompressor jpeg(640, 480, jpeg_quality)`
l. Create `ZstdCompressor zstd(640 * 480 * 2, zstd_level)` -- max input is 614,400 bytes

**3. Capture Thread:**
```cpp
std::thread capture_thread([&]() {
    while (!shutdown_flag.load(std::memory_order_acquire)) {
        try {
            CapturedFrame frame = camera.poll_frame();
            stats.frame_captured();
            queue.push(std::move(frame));

            // Duration limit check
            if (max_duration > 0 && stats.elapsed_seconds() >= max_duration) {
                shutdown_flag.store(true, std::memory_order_release);
            }
        } catch (const rs2::error& e) {
            fprintf(stderr, "RealSense error: %s\n", e.what());
            shutdown_flag.store(true, std::memory_order_release);
        }
    }
    queue.close();  // Signal writer to drain and exit
});
```

**4. Writer Thread:**
```cpp
std::thread writer_thread([&]() {
    while (true) {
        auto maybe_frame = queue.pop();
        if (!maybe_frame) break;  // Queue closed and empty

        auto& frame = *maybe_frame;

        // Compress RGB
        auto [jpeg_data, jpeg_size] = jpeg.compress(
            frame.rgb_data.data(), 640, 480);

        // Compress depth
        auto [zstd_data, zstd_size] = zstd.compress(
            frame.depth_data.data(), frame.depth_data.size());

        // Convert IMU samples to wire format
        std::vector<IMUSampleWire> imu_wire;
        for (const auto& imu : frame.imu_samples) {
            IMUSampleWire w;
            w.timestamp_us = imu.timestamp_us;
            w.accel_x = imu.accel[0]; w.accel_y = imu.accel[1]; w.accel_z = imu.accel[2];
            w.gyro_x = imu.gyro[0]; w.gyro_y = imu.gyro[1]; w.gyro_z = imu.gyro[2];
            imu_wire.push_back(w);
        }

        // Write to file
        writer.write_frame(
            jpeg_data, jpeg_size,
            zstd_data, zstd_size,
            frame.timestamp_us, frame.frame_number,
            imu_wire);

        stats.frame_written();
        stats.bytes_written(jpeg_size + zstd_size);
    }
});
```

**5. Stats Reporting (main thread):**
While capture and writer threads run, the main thread prints stats every 2 seconds:
```cpp
while (!shutdown_flag.load(std::memory_order_acquire)) {
    std::this_thread::sleep_for(std::chrono::seconds(2));
    fprintf(stderr, "\r%s", stats.summary().c_str());
    fflush(stderr);
}
```

**6. Shutdown Sequence:**
After shutdown_flag is set (signal, duration, or error):
```cpp
// Wait for capture to finish
capture_thread.join();

// Writer will drain remaining queue items then exit
writer_thread.join();

// Update dropped count from queue
stats.frames_dropped(queue.dropped());

// Finalize file (write index table + footer)
writer.finalize();

// Stop camera
camera.stop();

// Print final summary
fprintf(stderr, "\n\nRecording complete.\n%s\n", stats.summary().c_str());
fprintf(stderr, "Output: %s\n", output_filepath.c_str());

return 0;
```

**Error handling:**
- Wrap the entire main body in try/catch for `rs2::error` and `std::exception`
- Print error to stderr and return non-zero exit code
- If an exception occurs after the file is opened, attempt `writer.finalize()` in the catch block for best-effort recovery

**Key design points:**
- Compression happens in the writer thread (not capture thread) -- this prevents compression stalls from causing frame drops. At 640x480, JPEG (~1-3ms) + ZSTD (~0.5ms) + write (~0.1ms) totals well under 33ms.
- The capture thread does minimal work: poll + copy + enqueue. The copy (1.5MB memcpy) takes ~0.3ms on modern hardware.
- BoundedQueue's drop-oldest policy means the capture thread never blocks. If the writer falls behind, oldest frames are dropped and counted.
- The main thread only does stats printing -- it is not in the critical path.
