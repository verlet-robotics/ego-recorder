**src/storage/binary_format.h:**
Define all wire format types. Use `#pragma pack(push, 1)` for all structs to ensure no padding. All multi-byte values are little-endian (host byte order on x86 -- document this assumption).

Constants:
- `static constexpr uint8_t FILE_MAGIC[8] = {'E','G','O','R','E','C', 0x01, 0x00}` -- magic + version 1.0
- `static constexpr uint32_t FRAME_MAGIC = 0x46524D45` -- 'FRME' in little-endian
- `static constexpr uint32_t INDEX_MAGIC = 0x58444E49` -- 'INDX' in little-endian
- `static constexpr uint32_t FOOTER_MAGIC = 0x454E4F44` -- 'DONE' in little-endian

`struct FileHeader` (~512 bytes, padded with reserved bytes):
- `uint8_t magic[8]` -- FILE_MAGIC
- `uint32_t header_size` -- sizeof(FileHeader), for forward compatibility
- `uint32_t flags` -- bit 0: has_imu, bit 1: has_index
- `char serial_number[32]` -- null-terminated camera serial
- `float depth_scale` -- Z16 units to meters (typically 0.001)
- Depth intrinsics: `uint32_t depth_width, depth_height`, `float depth_fx, depth_fy, depth_ppx, depth_ppy`, `uint32_t depth_distortion_model`, `float depth_distortion_coeffs[5]`
- Color intrinsics: `uint32_t color_width, color_height`, `float color_fx, color_fy, color_ppx, color_ppy`, `uint32_t color_distortion_model`, `float color_distortion_coeffs[5]`
- Extrinsics: `float extrinsic_rotation[9]` (3x3 row-major), `float extrinsic_translation[3]` (meters)
- Session metadata: `char session_name[128]` (null-terminated), `uint64_t start_timestamp_us` (Unix epoch microseconds), `char usb_type[8]`
- Compression info: `uint8_t rgb_codec` (0=raw, 1=JPEG, 2=H264), `uint8_t depth_codec` (0=raw, 1=ZSTD, 2=Zdepth), `uint8_t rgb_quality` (0-100), `uint8_t zstd_level`
- `uint8_t reserved[128]` -- zero-filled, future use

`struct FrameBlockHeader`:
- `uint32_t magic` -- FRAME_MAGIC
- `uint32_t block_size` -- total size of this block including this header
- `uint64_t timestamp_us`
- `uint64_t frame_number`
- `uint32_t rgb_compressed_size`
- `uint32_t depth_compressed_size`
- `uint16_t imu_sample_count`
- `uint16_t flags` -- reserved

`struct IMUSampleWire` (wire format for IMU, 32 bytes):
- `uint64_t timestamp_us`
- `float accel_x, accel_y, accel_z`
- `float gyro_x, gyro_y, gyro_z`

`struct IndexEntry` (24 bytes):
- `uint64_t timestamp_us`
- `uint64_t file_offset` -- byte offset of FrameBlockHeader
- `uint64_t frame_number`

`struct FileFooter`:
- `uint32_t index_magic` -- INDEX_MAGIC
- `uint64_t index_offset` -- byte offset where index table starts
- `uint32_t index_entry_count`
- `uint64_t total_frames`
- `uint64_t total_duration_us` -- last timestamp - first timestamp
- `uint32_t footer_magic` -- FOOTER_MAGIC

Add `static_assert`s to verify struct sizes match expectations (e.g., `static_assert(sizeof(IndexEntry) == 24)`).

Use `#pragma pack(pop)` at the end.

**src/storage/file_writer.h/.cpp:**
Class `FileWriter`:
- Constructor: `FileWriter(const std::string& filepath)` -- opens file for binary writing (`std::ofstream` with `std::ios::binary`). Set a large write buffer (256KB) via `rdbuf()->pubsetbuf()`. Throw on open failure.
- `write_header(const FileHeader& header)` -- write header at file position 0. Store `header_size` for later offset calculation.
- `write_frame(const uint8_t* rgb_compressed, size_t rgb_size, const uint8_t* depth_compressed, size_t depth_size, uint64_t timestamp_us, uint64_t frame_number, const std::vector<IMUSampleWire>& imu_samples)`:
  - Record current file offset
  - Construct `FrameBlockHeader` with magic, sizes, timestamp, frame_number, imu_sample_count
  - Calculate `block_size` = sizeof(FrameBlockHeader) + rgb_size + depth_size + imu_samples.size() * sizeof(IMUSampleWire)
  - Write header, then rgb data, then depth data, then IMU samples
  - Append `IndexEntry{timestamp_us, file_offset, frame_number}` to in-memory `index_` vector
  - Track first and last timestamps for duration calculation
- `finalize()` -- called on clean shutdown:
  - Record index_offset (current file position)
  - Write all IndexEntry items sequentially
  - Construct and write FileFooter with index_offset, entry count, total_frames, total_duration_us, footer magic
  - Flush and close the file
- Destructor: if file is still open and `finalize()` was not called, attempt finalize (best-effort for crash recovery)
- Private: `std::ofstream file_`, `std::vector<IndexEntry> index_`, `uint64_t first_timestamp_`, `uint64_t last_timestamp_`, `bool finalized_`, write buffer char array

IMPORTANT: The index table is accumulated in memory (24 bytes per frame = ~2.5MB per hour at 30fps -- negligible). This is the standard pattern for append-on-close index tables.

IMPORTANT: Do NOT use `file_.write()` without checking `file_.good()` after writes. Log errors but do not throw from the writer thread (would crash the recording).

**src/utils/signal_handler.h/.cpp:**
Function `void setup_signal_handling(std::atomic<bool>& shutdown_flag)`:
- Block SIGTERM and SIGINT in ALL threads using `pthread_sigmask(SIG_BLOCK, ...)`. This MUST be called before creating any other threads so child threads inherit the blocked mask.
- Spawn a detached `std::thread` that calls `sigwait()` on the blocked set.
- When signal is received, set `shutdown_flag.store(true, std::memory_order_release)`.
- Print to stderr: `"\nReceived signal %d, shutting down...\n"` (stderr is safe here -- this is NOT an async signal handler, it is a synchronous sigwait thread).
- Include: `<signal.h>`, `<pthread.h>`, `<atomic>`, `<thread>`, `<cstdio>`

IMPORTANT: Use the POSIX `sigwait()` pattern, NOT `signal()` or `sigaction()`. The sigwait pattern is the only safe way to handle signals in a multi-threaded C++ program because it avoids async-signal-safety issues entirely.
