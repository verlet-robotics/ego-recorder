**EgorecFile class -- internal state:**
```cpp
class EgorecFile {
    std::ifstream file_;
    FileHeader header_;
    FileFooter footer_;
    bool has_footer_ = false;
    std::vector<IndexEntry> index_;
    uint64_t trailing_data_offset_ = 0;  // byte offset where trailing codec data starts

    // Zdepth decompressor
    ZdepthCompressor zdepth_;

    // H.264 decoder state
    AVCodecContext* dec_ctx_ = nullptr;
    AVFrame* yuv_frame_ = nullptr;
    AVPacket* pkt_ = nullptr;
    SwsContext* sws_ = nullptr;
    std::deque<std::vector<uint8_t>> decoded_rgb_queue_;  // buffered decoded frames
    std::vector<uint8_t> rgb_buffer_;  // scratch for sws_scale output

    uint64_t current_frame_ = 0;
    uint64_t total_frames_ = 0;
};
```

**Constructor (`EgorecFile(const std::string& path)`):**
1. Open file in binary read mode. Throw `std::runtime_error` if failed.
2. Read FileHeader. Validate magic starts with "EGOREC" (first 6 bytes). Check `magic[6] == 0x02` (v2 only, per locked decision). Throw descriptive error if v1: "V1 .egorec files are not supported by export tools. Re-record with v2 format."
3. Read footer: seek to `end - sizeof(FileFooter)`, read FileFooter, validate `footer_magic == FOOTER_MAGIC`.
4. If footer valid, read index table: seek to `footer.index_offset`, read `footer.index_entry_count` IndexEntry items into `index_`.
5. Calculate `trailing_data_offset_`: if index is non-empty, the last indexed frame ends at `index_.back().file_offset + [size of that frame block]`. To find this, seek to `index_.back().file_offset`, read a FrameBlockHeader, and compute `trailing_data_offset_ = index_.back().file_offset + fbh.block_size`. Any bytes between `trailing_data_offset_` and `footer.index_offset` are trailing H.264 codec flush data.
6. Set `total_frames_ = footer.total_frames` if footer valid, else 0.
7. Initialize ZdepthCompressor with header's depth dimensions: `zdepth_(header_.depth_width, header_.depth_height)`.
8. Initialize H.264 decoder:
   - `avcodec_find_decoder(AV_CODEC_ID_H264)` -- find the DECODER (not encoder)
   - Allocate AVCodecContext with `avcodec_alloc_context3`, open codec with `avcodec_open2`
   - Allocate AVFrame: `av_frame_alloc()`
   - Allocate AVPacket: `av_packet_alloc()`
   - Create SwsContext for YUV420P -> RGB24 conversion using header dimensions
   - Allocate rgb_buffer_: `header_.color_width * header_.color_height * 3` bytes
9. Seek file position back to `sizeof(FileHeader)` (start of frame data).

**`header()` method -- returns py::dict:**
Return a dict with all FileHeader fields:
- session_name (str), format_version (int from magic[6]), frame_count, duration_s
- start_ts_us, depth_width, depth_height, color_width, color_height, depth_scale
- depth_fx/fy/ppx/ppy, depth_distortion_model, depth_distortion (list of 5 floats)
- color_fx/fy/ppx/ppy, color_distortion_model, color_distortion (list of 5 floats)
- extrinsic_R (list of 9 floats, row-major), extrinsic_t (list of 3 floats)
- rgb_codec, depth_codec, has_imu (bool from flags & 0x01)
- serial_number, usb_type

**`frame_count()` method:**
Return `total_frames_`.

**Destructor:**
- `sws_freeContext(sws_)` if non-null
- `av_frame_free(&yuv_frame_)` if non-null
- `av_packet_free(&pkt_)` if non-null
- `avcodec_free_context(&dec_ctx_)` if non-null
- File closes automatically (RAII)
- ZdepthCompressor destructs via RAII

**Add to src/python/egorec_reader.cpp (continuing from Task 1):**

**`read_frame(uint64_t index)` internal method:**
1. First check `decoded_rgb_queue_` -- if it has buffered decoded RGB frames from a previous multi-output decode, pop and use the front entry instead of reading a new frame.
2. If we have the index table, seek to `index_[index].file_offset`. Otherwise, file position should already be at the next frame from the previous sequential read.
3. Read FrameBlockHeader. Validate `magic == FRAME_MAGIC`.
4. Read `rgb_compressed_size` bytes of H.264 data into a buffer.
5. Read `depth_compressed_size` bytes of Zdepth data into a buffer.
6. Skip `imu_sample_count * sizeof(IMUSampleWire)` bytes (IMU not exported to Python in this version).

**H.264 decode logic:**
- If `rgb_compressed_size > 0`:
  - Set `pkt_->data` and `pkt_->size` from the H.264 buffer.
  - Call `avcodec_send_packet(dec_ctx_, pkt_)`.
  - Call `avcodec_receive_frame(dec_ctx_, yuv_frame_)` in a LOOP until EAGAIN.
  - For each received frame: convert YUV420P -> RGB24 via `sws_scale` into `rgb_buffer_`, then copy into a `std::vector<uint8_t>` and push to `decoded_rgb_queue_`.
- If `rgb_compressed_size == 0`:
  - The encoder returned empty data for this frame (buffering). Check decoder for any buffered output by calling `avcodec_receive_frame` -- it may have been produced by a previous send_packet.

**IMPORTANT decoder subtlety:** The encoder might return data for frame N along with frame N+1's packet. The decoder then produces TWO frames from one packet. Handle by calling receive_frame in a loop and pushing all results to `decoded_rgb_queue_`. Pop one per `read_frame()` call.

**Zdepth decompress logic:**
- If `depth_compressed_size > 0`:
  - Call `zdepth_.decompress(depth_data, depth_size)` to get `std::vector<uint16_t>`.
- If `depth_compressed_size == 0`: create zero-filled depth vector.

**Frame dict returned to Python:**
```python
{
    "timestamp_us": int,
    "timestamp_relative_s": float,  # (timestamp_us - start_ts_us) / 1e6
    "frame_number": int,
    "rgb": np.ndarray(dtype=uint8, shape=(H, W, 3)),
    "depth": np.ndarray(dtype=uint16, shape=(H, W)),
}
```

Create numpy arrays using `py::array_t<uint8_t>` with shape `{height, width, 3}` for RGB and `py::array_t<uint16_t>` with shape `{height, width}` for depth. Copy data into the arrays' mutable buffers.

**H.264 decoder flush at end of iteration:**
When `current_frame_ >= total_frames_`:
1. First, read and feed any trailing codec flush data to the decoder. Read bytes from `trailing_data_offset_` to `footer_.index_offset` as raw H.264 packets. Feed them to `avcodec_send_packet`. Drain decoded frames into `decoded_rgb_queue_`.
2. Then flush the decoder: `avcodec_send_packet(dec_ctx_, nullptr)`. Drain remaining frames with `avcodec_receive_frame` loop into `decoded_rgb_queue_`.
3. If `decoded_rgb_queue_` still has frames, return them (they correspond to trailing flush frames that pair with the last depth frames).

**FrameIterator class:**
```cpp
struct FrameIterator {
    EgorecFile* file;
    uint64_t current;

    py::dict next() {
        // check if there are still frames or buffered decoded data
        if (current >= file->total_frames_ && file->decoded_rgb_queue_.empty()) {
            throw py::stop_iteration();
        }
        return file->read_frame(current++);
    }
};
```

Register FrameIterator with `__iter__` (returns self) and `__next__` (calls next()).

**`frames_iterator()` method on EgorecFile:**
- Seek to `sizeof(FileHeader)` (restart from beginning of frame data).
- Reset `current_frame_ = 0`.
- Clear `decoded_rgb_queue_`.
- Flush and reinitialize the H.264 decoder (to reset state for a fresh iteration).
- Return a FrameIterator pointing to this file.

**PYBIND11_MODULE definition:**
```cpp
namespace py = pybind11;

PYBIND11_MODULE(egorec_reader, m) {
    m.doc() = "C++ reader for .egorec v2 files";

    py::class_<FrameIterator>(m, "FrameIterator")
        .def("__iter__", [](FrameIterator& self) -> FrameIterator& { return self; })
        .def("__next__", &FrameIterator::next);

    py::class_<EgorecFile>(m, "EgorecFile")
        .def(py::init<const std::string&>())
        .def("header", &EgorecFile::header)
        .def("frame_count", &EgorecFile::frame_count)
        .def("frames", &EgorecFile::frames_iterator,
             py::keep_alive<0, 1>());  // iterator refs file
}
```

Use `py::keep_alive<0, 1>()` on frames() to ensure the EgorecFile stays alive while the iterator exists.
