<objective>
Implement the RealSense camera pipeline wrapper that handles device initialization, configuration, intrinsics/extrinsics extraction, IMU detection, warmup, and frame polling.

Purpose: This is the hardware interface layer. It encapsulates all librealsense2 SDK interactions behind a clean C++ API so the main orchestration can simply call `poll_frame()` to get a `CapturedFrame`. Correct configuration (auto-exposure, global time, USB detection, warmup) is critical for reliable 30fps capture.

Output: A fully configured RealSense pipeline wrapper that produces `CapturedFrame` structs ready for compression and writing.
</objective>

**src/capture/pipeline.cpp:**

`configure_and_start(int warmup_frames)` implementation sequence:

1. **Configure streams:**
   ```cpp
   rs2::config cfg;
   cfg.enable_stream(RS2_STREAM_COLOR, 640, 480, RS2_FORMAT_RGB8, 30);
   cfg.enable_stream(RS2_STREAM_DEPTH, 640, 480, RS2_FORMAT_Z16, 30);
   ```

2. **Attempt IMU streams (D435i detection):**
   - Try to enable `RS2_STREAM_ACCEL` and `RS2_STREAM_GYRO` with `RS2_FORMAT_MOTION_XYZ32F`
   - Use try/catch: if `pipe_.start(cfg)` throws because IMU is not available (D435 without IMU), catch the exception, disable IMU streams in config, and retry `pipe_.start(cfg)` without IMU
   - Set `has_imu_` accordingly
   - Print to stderr: "IMU detected (D435i mode)" or "No IMU detected (D435 mode)"

   Concrete approach:
   ```cpp
   // First attempt with IMU
   cfg.enable_stream(RS2_STREAM_ACCEL, RS2_FORMAT_MOTION_XYZ32F);
   cfg.enable_stream(RS2_STREAM_GYRO, RS2_FORMAT_MOTION_XYZ32F);
   try {
       profile_ = pipe_.start(cfg);
       has_imu_ = true;
   } catch (const rs2::error&) {
       // Retry without IMU
       rs2::config cfg_no_imu;
       cfg_no_imu.enable_stream(RS2_STREAM_COLOR, 640, 480, RS2_FORMAT_RGB8, 30);
       cfg_no_imu.enable_stream(RS2_STREAM_DEPTH, 640, 480, RS2_FORMAT_Z16, 30);
       profile_ = pipe_.start(cfg_no_imu);
       has_imu_ = false;
   }
   ```

3. **Extract device info:**
   ```cpp
   auto dev = profile_.get_device();
   serial_number_ = dev.get_info(RS2_CAMERA_INFO_SERIAL_NUMBER);
   usb_type_ = dev.get_info(RS2_CAMERA_INFO_USB_TYPE_DESCRIPTOR);
   ```
   - If `usb_type_` starts with "2.", print warning to stderr: "WARNING: USB 2.0 detected. Bandwidth may be insufficient for 640x480@30fps RGB+depth. Use a USB 3.0 port and cable."

4. **Disable auto-exposure priority:**
   ```cpp
   auto color_sensor = profile_.get_device().first<rs2::color_sensor>();
   color_sensor.set_option(RS2_OPTION_AUTO_EXPOSURE_PRIORITY, 0.0f);
   ```

5. **Enable global time synchronization:**
   ```cpp
   auto depth_sensor = profile_.get_device().first<rs2::depth_sensor>();
   if (depth_sensor.supports(RS2_OPTION_GLOBAL_TIME_ENABLED)) {
       depth_sensor.set_option(RS2_OPTION_GLOBAL_TIME_ENABLED, 1.0f);
   }
   ```

6. **Extract depth scale:**
   ```cpp
   depth_scale_ = depth_sensor.get_depth_scale();
   ```

7. **Extract intrinsics and extrinsics:**
   ```cpp
   auto depth_stream = profile_.get_stream(RS2_STREAM_DEPTH).as<rs2::video_stream_profile>();
   auto color_stream = profile_.get_stream(RS2_STREAM_COLOR).as<rs2::video_stream_profile>();
   depth_intrinsics_ = depth_stream.get_intrinsics();
   color_intrinsics_ = color_stream.get_intrinsics();
   depth_to_color_extrinsics_ = depth_stream.get_extrinsics_to(color_stream);
   ```

8. **Warmup -- drop first N frames:**
   ```cpp
   fprintf(stderr, "Warming up camera (%d frames)...\n", warmup_frames);
   for (int i = 0; i < warmup_frames; ++i) {
       pipe_.wait_for_frames();
   }
   fprintf(stderr, "Camera ready.\n");
   ```

9. Initialize `frame_counter_ = 0`

**Getter implementations:**
All getter methods are trivial one-liner const methods returning the stored private members. Implement them inline in the header or in pipeline.cpp -- either is fine.

`poll_frame()` implementation:
- Call `pipe_.wait_for_frames()` to get `rs2::frameset`
- Extract color frame: `frames.get_color_frame()`
- Extract depth frame: `frames.get_depth_frame()`
- Create `CapturedFrame cf`
- Set `cf.timestamp_us = static_cast<uint64_t>(color.get_timestamp() * 1000.0)` -- SDK returns milliseconds, convert to microseconds
- Set `cf.frame_number = frame_counter_++`
- Copy RGB data: `cf.rgb_data.assign(ptr, ptr + stride * height)` where ptr is `static_cast<const uint8_t*>(color.get_data())`
- Copy depth data: `cf.depth_data.assign(ptr, ptr + stride * height)` where ptr is `static_cast<const uint8_t*>(depth.get_data())`
- If `has_imu_`: iterate frameset for motion frames, populate `cf.imu_samples` vector with IMUSample structs from `rs2::motion_frame::get_motion_data()`. Note: IMU frames arrive at higher rates (200-400Hz) than RGB/depth (30fps), so there may be multiple IMU samples per frameset, or IMU may come through the callback path. For the MVP polling approach, iterate `frames` for any motion frames and collect them.
- Return `cf` (moved)

IMPORTANT: The data pointed to by `color.get_data()` is invalidated when the `rs2::frameset` goes out of scope. The memcpy into `CapturedFrame` vectors MUST happen before the frameset is released. This is already handled by the `.assign()` copy.

IMPORTANT: Do NOT use `rs2::frame::keep()`. The CapturedFrame owns its data via vectors. The SDK frame is released when `poll_frame()` returns.
